# 利用者向け操作マニュアル

社内文書検索AIは、社内規程・マニュアルの内容を質問すると、**社内文書だけを根拠に**回答し、根拠となった文書とページを示すツールです。

## 1. ログイン

1. 管理者から案内された URL を開く（PC・スマートフォンのブラウザで利用できます）。
2. メールアドレスとパスワードを入力して **ログイン**。
3. 「ログインできませんでした」と表示された場合（理由は安全のため表示されません）: 入力内容を確認し、解決しなければ管理者に連絡してください。
4. 「利用権限がありません」と表示された場合: アカウントはありますが利用が許可されていません。管理者に連絡してください。

> 新規登録の画面はありません。アカウントは管理者が発行します。

## 2. 質問する

1. 画面下の入力欄に質問を入力します（1000 文字まで）。
   - 例: 「出張の宿泊費の上限はいくらですか？」
2. **Enter** または **送信** ボタンで送信します。改行したいときは **Shift + Enter**。
3. 回答の作成中は「文書を検索して回答を作成しています…」と表示されます。通常は数秒で表示されます。

**よい質問のコツ**

- 1 回の質問で 1 つのことを聞く（「申請期限と精算期限は？」程度なら可）
- 「出張旅費」「会議室の予約」など、文書で使われていそうな言葉を入れる

## 3. 回答と出典の見方

- 回答の本文中の **[1]** などの番号は、下に表示される **出典** の番号に対応します。
- 出典には **ファイル名・ページ番号・見出し・抜粋** が表示されます。
- 出典をクリックすると、新しいタブで **該当 PDF のそのページ** が開きます。重要な判断の前には必ず原文を確認してください。

## 4. 「該当する情報が見つかりません」と表示されたら

- 閲覧できる文書に、その質問への答えが書かれていない場合の表示です（AI が推測で回答しないための仕様です）。
- 言い回しを変えて再度質問するか、担当部署に直接問い合わせてください。

## 5. エラー表示

| 表示 | 対応 |
| --- | --- |
| ログインの有効期限が切れました | 再度ログインしてください |
| しばらく時間をおいて再度お試しください | 短時間に多数の質問をした場合などに表示されます。1 分ほど待ってください |
| 外部サービスに接続できませんでした | 一時的な障害です。時間をおいて再度お試しください |
| 通信に失敗しました | ネットワーク接続を確認して再度お試しください |
| エラーが発生しました | 続く場合は、発生時刻と操作内容を管理者に連絡してください |

## 6. 注意事項

- 回答は AI が文書の抜粋から作成したものです。**最終的な判断は出典の原文で確認**してください。
- 質問欄に **個人情報・パスワード・顧客情報を入力しない** でください（質問は回答作成のため外部の AI サービスに送信されます）。
- 会話の履歴は画面を閉じると消えます（保存されません）。
- 対象文書は管理者が取り込んだ PDF です（学習用 MVP では架空のダミー文書のみを使用します）。
